Integration Plan

Compose Support for Termux-Ghostty

Integrating Chuchu's Jetpack Compose rendering canvas components directly into termux-ghostty.

Integrating Chuchu's Compose Components

Instead of bringing over Chuchu's Native/JNI bridge code (which lacks termux-ghostty's performance optimizations and creates high GC pressure), the ideal integration strategy is to adapt Chuchu's Composable canvas drawing logic to read from termux-ghostty's existing direct-buffer-backed ScreenSnapshot system.

Core Benefit

This allows termux-ghostty to support native Jetpack Compose UIs while maintaining the highly optimized, lock-free FrameDelta and RenderFrameCache backend architecture.

Architectural Options for Module Layout

Option A: Separate Module (Recommended)

Create a new sub-module: terminal-view-compose.

  • Keeps base terminal-view clean of Compose dependencies.
  • Exposes only the TerminalCanvas Composable.
  • Enables Compose only in the new sub-module.

Option B: Unified Module

Enable Jetpack Compose features directly in terminal-view's build.gradle.

  • Allows developers to import a single library.
  • Adds Compose dependencies to all consumers of the view library.

Mapping termux-ghostty Snapshots to Compose Canvas

The code below demonstrates how to adapt Chuchu's TerminalCanvas to traverse the optimized ScreenSnapshot structure of termux-ghostty. This avoids array rebuilding and allocations during draw iterations:

TerminalCanvas.kt Blueprint 
import androidx.compose.foundation.Canvas
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.graphics.drawscope.drawIntoCanvas
import androidx.compose.ui.graphics.nativeCanvas
import androidx.compose.ui.platform.LocalDensity
import androidx.compose.ui.unit.sp
import android.graphics.Paint
import android.graphics.Typeface
import com.termux.terminal.ScreenSnapshot
import com.termux.terminal.TextStyle

@Composable
fun TerminalCanvas(
    snapshot: ScreenSnapshot,
    modifier: Modifier = Modifier,
    fontSizeSp: Float = 14f
) {
    val density = LocalDensity.current
    val fontSizePx = with(density) { fontSizeSp.sp.toPx() }
    
    val textPaint = remember(fontSizePx) {
        Paint().apply {
            isAntiAlias = true
            textSize = fontSizePx
            typeface = Typeface.MONOSPACE
        }
    }
    
    val fontMetrics = textPaint.fontMetrics
    val cellHeight = fontMetrics.descent - fontMetrics.ascent
    val cellWidth = textPaint.measureText("X")
    val baselineOffset = -fontMetrics.ascent

    Canvas(modifier = modifier.fillMaxSize()) {
        drawIntoCanvas { canvas ->
            val nativeCanvas = canvas.nativeCanvas
            val rows = snapshot.rows
            val cols = snapshot.columns

            // Draw default background
            val bgPaletteColor = snapshot.getPaletteColor(TextStyle.COLOR_INDEX_BACKGROUND)
            drawRect(color = Color(bgPaletteColor))

            for (rowIndex in 0 until rows) {
                val row = snapshot.getRow(rowIndex)
                val yOffset = rowIndex * cellHeight
                val baseline = yOffset + baselineOffset

                for (col in 0 until cols) {
                    val textStart = row.getCellTextStart(col)
                    val textLength = row.getCellTextLength(col)
                    val displayWidth = row.getCellDisplayWidth(col)
                    val style = row.getStyle(col)

                    if (displayWidth <= 0) continue

                    val effect = TextStyle.decodeEffect(style)
                    val isBold = (effect and TextStyle.CHARACTER_ATTRIBUTE_BOLD) != 0
                    val isItalic = (effect and TextStyle.CHARACTER_ATTRIBUTE_ITALIC) != 0

                    if (textLength > 0) {
                        textPaint.isFakeBoldText = isBold
                        textPaint.textSkewX = if (isItalic) -0.25f else 0f
                        
                        val textSegment = String(row.text, textStart, textLength)
                        nativeCanvas.drawText(
                            textSegment,
                            col * cellWidth,
                            baseline,
                            textPaint
                        )
                    }
                }
            }
        }
    }
}

Gestures & Interaction Mapping

When porting Chuchu's Compose gesture code, we must translate pointer inputs into updates on termux-ghostty's active terminal session:

  • Pinch-to-Zoom (Font Scaling):

    Use Compose's rememberTransformableState to capture scale multipliers and trigger updates in termux-ghostty's session font configurations.

  • Selections:

    Construct a helper class that converts touch coordinate offsets (X, Y) into character cell indices using cellWidth and cellHeight measurements. Update the text selection controller in-place.

  • Custom Scroll/Fling:

    Map Compose pointer swipe events to TerminalSession.setGhosttyTopRow(...) to trigger updates in the RenderFrameCache.

Implementation Roadmap

Follow these steps to port Chuchu's rendering canvas into termux-ghostty:

  1. Step 1: Module Creation

    Create the terminal-view-compose module and configure the Kotlin Compose compiler plugin inside the Gradle settings.

  2. Step 2: Add Composable Canvas

    Implement the TerminalCanvas Composable in the new module. Write parser adapters to render text sequences from ScreenSnapshot's UTF-16 row arrays.

  3. Step 3: Setup Pointer Inputs

    Port Chuchu's gesture handlers to Compose pointerInput modifiers, binding scroll and scale updates to TerminalSession methods.

  4. Step 4: Expose Sample Activity

    Create a sample Activity in the app module to test and demonstrate rendering the terminal via Compose's TerminalCanvas side-by-side with standard XML layouts.
